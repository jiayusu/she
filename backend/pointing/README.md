# 指向识别模块（浏览器端）PRD · V1.0

## 1. 背景与目标

万物模式的"指向"交互：孩子指着物件，系统知道指的是哪一个。硬件版（S3+端侧视觉）上市前，先在**浏览器端实现**（手机/平板摄像头 + MediaPipe），验证"指哪哪开口"的交互成立，并沉淀手势判定与确认话术逻辑供硬件版复用。

**北极星指标**：指向窗口内正确选中目标物件（孩子意图物件）的比例 ≥85%；端到端（按下蛇首→听到回应）≤2.5s。

## 2. 范围

| In Scope | Out of Scope |
|---|---|
| 浏览器端指向手势检测（MediaPipe Hands） | 硬件摄像头端侧推理（S3 版规划） |
| 2D 射线求交选物 + 确认话术兜底 | 深度/3D 指向（L2/L3 方案） |
| 多候选场景的选择策略 | 连续视频流实时跟随 |
| 失败兜底链 | 手势词库扩展（V1.1：挥手/鼓掌） |

## 3. 用户故事

- 孩子指着冰箱，王冠说"你是想问冰箱吗？"→ 孩子点头/说"对"→ 冰箱开口。指错了也能被纠正，孩子重新指一次。
- 孩子只是伸手拿杯子（不是指向），系统**不应**触发万物模式。
- 家长在 App 能看到"今天孩子指了 8 次东西，对了 7 次"。

## 4. 功能需求

| 编号 | 需求 | 优先级 | 验收 |
|---|---|---|---|
| FR-P01 | 唤醒触发：点击页面"指它"按钮或语音"那是什么"拉起指向窗口（摄像头启动 + 5 帧突发采集） | P0 | 从触发到开始采帧 ≤1s |
| FR-P02 | 指向手势判定：食指伸直 + 其余手指弯曲 + 手腕可见（21 关键点夹角规则） | P0 | 自采测试集（20 个孩子×10 次）手势召回 ≥90%；**非指向伸手误触发 ≤5%** |
| FR-P03 | 方向射线：手腕→食指根向量延长，与 YOLO 检出框求交；多交取最近，无交取离指尖最近框 | P0 | 正指场景选物准确率 ≥85% |
| FR-P04 | **确认话术**：选中后先问"你是想问 X 吗？"，孩子确认（是/对/点头语音）才进入生成；孩子说"不是"→ 选第二候选再问，最多 2 轮 | P0 | 确认轮次 ≤2；孩子任意中文肯定/否定表达都能识别 |
| FR-P05 | 全链路兜底：手势未检出 → 按画面中心框选 + 确认话术；检出 0 物件 → "再对准一点"；LLM 失败 → 模板回应。**任何路径无空响应** | P0 | 断网/暗光/遮挡三场景均有回应 |
| FR-P06 | 指向窗口 2 秒超时自动关闭摄像头（事件驱动，非持续采集） | P0 | 窗口外摄像头流必须 stop（隐私验收） |
| FR-P07 | 手势置信度分级：5 帧中 ≥3 帧命中=直接选物+轻确认；1-2 帧命中=重确认（"你是指这个还是那个？"）；0 帧=中心框兜底 | P1 | 分级逻辑生效 |
| FR-P08 | 埋点回流：每次指向记录 {手势帧数, 选中框, 确认结果, 纠正次数} | P1 | 报表可见"指向准确率"趋势 |
| FR-P09 | 家长 App 端"今日万物记录"（指了什么/对了几次） | P2 | 与视觉模块 FR-V08 共用 |
| FR-P10 | 小智联动：按老颞蛇首 → 推送拍照指令到浏览器页面（WebSocket）自动触发 FR-P01 | P2 | 王冠→浏览器联动走通 |

## 5. 非功能需求

| 项 | 指标 |
|---|---|
| 端侧兼容 | iOS Safari 15+ / Android Chrome 100+，中低端机（4GB 内存）可跑 MediaPipe Hands |
| 计算开销 | 指向窗口内 MediaPipe 仅处理 5 帧；窗口外零计算 |
| 隐私 | 帧数据只在内存处理，**不落盘不上传原图**；上传服务器的仅为检测后裁切区域（可选关闭） |
| 弱光/逆光 | 手势检出失败自动走兜底链，不报错 |

## 6. 关键流程

```
触发(FR-P01)
  └─ 采集5帧
       ├─ 手势判定(FR-P02) ──命中帧数──┬─ ≥3帧 → 射线选物(FR-P03) → 轻确认(FR-P04)
       │                              ├─ 1-2帧 → 选物 → 重确认(FR-P07)
       │                              └─ 0帧   → 中心框兜底 + 确认
       └─ YOLO 检出 0 框 → "再对准一点"(FR-P05)
确认通过 → 进视觉模块 /api/see 生成回应
孩子说"不是" → 第二候选 → 再问（≤2轮）→ 仍否 → "那我们一起看看别的东西吧"（优雅退出）
```

## 7. 接口

```
浏览器端（纯端侧，无后端依赖）：
  MediaPipe Hands (JS) → 手势判定 + 关键点
  YOLOv8n (ONNX Runtime Web / 服务端) → 物件框

服务端复用：
  POST /api/see { image, level, bbox_hint }  ← 视觉模块已有，加 bbox_hint 提升选物精度

新增：
  WS /ws/crown → 浏览器监听"请拍照"指令（FR-P10 小智联动）
  POST /admin/pointing-stats → 指向准确率报表（FR-P08）
```

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 儿童手型小，MediaPipe 关键点漂移 | 自采 20 个孩子手部数据校正判定阈值；判定不依赖绝对坐标而依赖向量夹角（尺度不变） |
| 孩子"指"的动作不标准（整个巴掌伸过去） | FR-P02 规则放宽一档（食指+中指并伸也算指向），用确认话术吸收残余误差 |
| 确认话术多一轮=延迟+0.8s | 仅在置信度分级为"重确认"时启用；轻确认用"你是想问 X 吗"+2 秒无否定视为确认（快进路径） |
| 浏览器兼容性碎片化 | 首版只保 iOS Safari + Chrome； |
