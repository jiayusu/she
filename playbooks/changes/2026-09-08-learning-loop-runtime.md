# Change: Learning-oriented bounded Director loop

**Commit binding:** Same commit as this record.

## Summary

Evaluate the preceding planned target/support before selecting the next action.
Use at most two unsuccessful replies before listening-only participation; uncertain
ASR does not count as a failure. Keep temporary session context bounded and isolated.
Add fixed internal lifecycle hooks with minimal trace metadata. The direct entry no
longer sends raw answers to the legacy JSONL fallback or promotes durable mastery.

## Layer

Agent and shared contract definition. Existing safety hooks and fixed Assessment
implementation are unchanged. No KG or Memory data files are edited.

## Contract impact

Backward-compatible response addition `learning_loop`, defined first in shared
contracts with valid/invalid fixtures. Intentional behavior change: no learning_event_id
is generated by /agent/direct until a real Shared State evidence writer is integrated.

## Files

Director loop, lifecycle module, app integration, types, tests, component/API docs,
shared learning-loop schema and fixtures. Detailed actual scope: `agents/director/docs/learning-loop.md`.

## Verification

First five new behavioral tests failed against the old implementation. After changes,
all 76 Director tests pass, including actual HTTP/no raw file write and 10 loop cases.
Director typecheck passes; shared contracts 14 tests and validator pass.
Final repository verification passes all 18 checks. Director deployment is separate
from the current Web/Gateway Compose stack; its HTTP integration is verified in tests.

## Rollback

Revert the runtime commit and redeploy the Director. Session context is temporary and
resets on restart. Review the old raw JSONL fallback before restoring prior behavior.
